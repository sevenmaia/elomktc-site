# LP Conversion Flow

Cada seção responde a uma dúvida:

- Hero → O que você faz por mim?
- Trust → Posso confiar?
- Serviços → Resolve meu problema?
- Sobre → Quem está por trás?
- Processo → Como funciona?
- Prova → Funcionou para alguém?
- FAQ → E minhas objeções?
- CTA → O que faço agora?

Se uma seção não responde uma pergunta real, considere removê-la.
