# AVSM LP

## Missão
Criar páginas comerciais eficientes sem transformar uma landing page em experimento técnico.

## Prioridades

```text
clareza
↓
autoridade
↓
confiança
↓
prova
↓
CTA
↓
performance
```

## Estrutura-base

```text
Header
Hero
Trust / Diferenciais
Serviços / Benefícios
Autoridade / Sobre
Como funciona
Prova social
FAQ
CTA final
Footer
```

Não é obrigatório usar todas.

## Motion
Permitido:
- Level 0
- Level 1
- Level 2

Preferir CSS quando suficiente.

## Evitar
- Three.js;
- R3F;
- WebGL;
- shaders;
- 3D decorativo;
- GSAP complexo;
- smooth scroll sem necessidade;
- scroll hijacking;
- cursor custom;
- page transition cinematográfica;
- partículas.

## Layout
Não espremer.

Desktop:
- bastante espaço vertical;
- texto com largura controlada;
- máximo aproximado de 3 cards textuais por linha;
- CTAs claros.

Mobile:
- 1 coluna;
- conteúdo reorganizado;
- botões confortáveis;
- não apenas reduzir desktop.

## Performance
A página deve carregar rápido em conexão móvel comum.
