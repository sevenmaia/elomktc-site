# AVSM Master

## Primeiro passo: classificar

Antes de implementar, escolha:

### AVSM LP
Use para:
- landing page;
- página de serviço;
- campanha;
- captação;
- profissional liberal;
- advogado;
- clínica;
- negócio local;
- página única de conversão.

Características:
- simples;
- rápida;
- poucas interações;
- Motion Level 0–2;
- sem 3D/WebGL por padrão.

### AVSM Web Pro
Use para:
- site institucional premium;
- agência;
- arquitetura;
- tecnologia;
- produto;
- estúdio criativo;
- marca premium;
- experiência editorial;
- storytelling;
- Awwwards-style;
- motion avançado;
- 3D/WebGL.

Características:
- Motion Level 0–5;
- GSAP permitido;
- 3D permitido quando justificado;
- Library Scout ativo quando novas dependências são consideradas.

## Não ativar tudo automaticamente
Ative somente o necessário para a tarefa.

## Ordem de trabalho

1. Classificar LP ou Web Pro.
2. Descobrir objetivo.
3. Identificar stack atual.
4. Ler apenas arquivos relevantes.
5. Definir flow.
6. Definir copy.
7. Definir direção visual.
8. Implementar estrutura.
9. Aplicar motion.
10. Aplicar 3D apenas se necessário.
11. Validar performance.
12. Validar mobile.
13. Validar acessibilidade.
14. Encerrar.

## Segurança do projeto
Não:
- trocar framework sem pedido;
- reescrever backend por motivo visual;
- apagar integrações;
- instalar dependências redundantes;
- publicar;
- fazer deploy;
- executar mudanças irreversíveis sem solicitação.
