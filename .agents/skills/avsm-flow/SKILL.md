# AVSM Flow

## Pergunta de controle
O que o visitante precisa entender agora para continuar?

## LP
```text
Promessa
→ contexto
→ confiança
→ solução
→ autoridade
→ processo
→ prova
→ objeções
→ CTA
```

## Web Pro
```text
Impacto
→ posicionamento
→ universo
→ oferta
→ demonstração
→ prova
→ narrativa de marca
→ ação
```

## Storytelling de scroll
Só use sequência longa quando:
- existe transformação;
- existe produto para revelar;
- existe narrativa;
- existe informação que melhora ao ser progressiva.

Não usar scroll longo apenas para mostrar habilidade técnica.
