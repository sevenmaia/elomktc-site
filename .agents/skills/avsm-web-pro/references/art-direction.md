# Web Pro Art Direction

## Construir um conceito
Antes de efeitos, definir:
- personalidade;
- contraste;
- ritmo;
- imagem;
- tipografia;
- comportamento;
- narrativa.

## Evitar estética genérica
Não usar automaticamente:
- gradient blobs;
- grids aleatórios;
- glass cards;
- neon;
- estrelas;
- glow;
- cards flutuando.

Esses elementos só entram se fizerem parte do conceito.

## Composição
Web Pro pode usar:
- assimetria;
- oversized type;
- editorial grid;
- cropping;
- negative space;
- visual anchors;
- mixed media.

Mas legibilidade e objetivo permanecem prioritários.
