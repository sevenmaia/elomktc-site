# AVSM Web Pro

## Missão
Construir sites premium cuja tecnologia esteja subordinada à ideia criativa.

## Permitido quando justificado
- GSAP;
- ScrollTrigger;
- Motion;
- Lenis;
- Three.js;
- React Three Fiber;
- Drei;
- WebGL;
- OGL;
- PixiJS;
- Canvas;
- SVG avançado;
- shaders;
- GLTF/GLB;
- Rive;
- Lottie;
- vídeo;
- áudio;
- interactive typography;
- page transitions;
- parallax;
- physics;
- partículas.

## Nunca usar por status
"Premium" não significa adicionar tudo.

## Motion Levels

### Level 0
Estático.

### Level 1
Microinterações.

### Level 2
Reveal, hover, small scroll motion.

### Level 3
GSAP / ScrollTrigger / storytelling.

### Level 4
Experiência cinematográfica.

### Level 5
3D/WebGL/shaders/imersivo.

## Library Scout
Antes de adicionar uma nova biblioteca:
- consultar `avsm-library-scout`;
- comparar com stack atual;
- verificar licença e manutenção;
- evitar duplicação.

## 3D
Quando 3D for central:
- usar `avsm-3d`;
- carregar progressivamente;
- fornecer fallback;
- controlar custo em mobile.
