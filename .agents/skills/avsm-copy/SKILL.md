# AVSM Copy

## LP Mode
Priorizar:
- clareza;
- benefício;
- prova;
- redução de objeção;
- CTA.

Evitar:
- textão;
- clichê;
- promessa vazia;
- jargão;
- headline bonita mas incompreensível.

## Web Pro Mode
Pode usar:
- storytelling;
- editorial copy;
- manifesto;
- headline conceitual;
- frases progressivas;
- microcopy;
- narrativa sincronizada com scroll.

## Regra
A copy precisa funcionar sem animação.

Motion reforça mensagem; não substitui mensagem.

## Exemplo estrutural Web Pro

```text
Headline curta
↓
contraste
↓
revelação
↓
explicação
↓
prova
↓
ação
```
