# AVSM Quality Bar

## Toda interface precisa passar por estes testes

### Clareza
- O propósito da página é entendido rapidamente?
- O próximo passo é óbvio?

### Hierarquia
- H1 realmente domina?
- Texto secundário parece secundário?
- CTAs competem ou possuem prioridade?

### Espaçamento
- A página respira?
- Há seções espremidas?
- Cards estão grandes o suficiente para o conteúdo?

### Consistência
- Radius, bordas, grid, tipografia e ícones seguem um sistema?
- Há elementos inseridos apenas para "encher"?

### Realismo
- O resultado parece produto real?
- Evita aparência genérica de template/IA?

### Performance
- A experiência visual justifica o custo técnico?

### Mobile
- Mobile foi projetado, não apenas reduzido?
