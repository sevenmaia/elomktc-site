# AVSM Design System — Base

Quando o projeto é da marca Arthur VSM:

- preto: `#101010`
- verde AVSM: `#ECFF8C`
- branco: `#FFFFFF`
- cinzas neutros

Tipografia preferencial:
- Telegraf — display/editorial
- Inter — body/UI
- Tomorrow — labels/técnico
- Bungee — pontual

## Importante

A metodologia AVSM não obriga clientes a usar a paleta AVSM.

Se houver uma identidade visual própria:
- preserve a marca;
- use AVSM como metodologia de qualidade;
- não pinte tudo de verde.
