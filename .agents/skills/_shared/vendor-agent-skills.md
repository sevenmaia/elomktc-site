# Vendor Agent Skills

Algumas bibliotecas mantêm Skills próprias para agentes.

## GSAP

A organização oficial GreenSock mantém um repositório `gsap-skills`.

Fonte:
`https://github.com/greensock/gsap-skills`

Quando GSAP for parte central da tarefa:
1. verificar se essas Skills podem ser usadas pelo ambiente atual;
2. preferir instruções oficiais às receitas antigas;
3. não copiar cegamente versões incompatíveis com a stack.

## PixiJS

A organização PixiJS mantém `pixijs-skills`.

Fonte:
`https://github.com/pixijs/pixijs-skills`

Quando PixiJS for usado:
- preferir conhecimento/instruções oficiais atualizados;
- confirmar versão e API antes de implementar.

## Regra

Não instalar Skills de terceiros automaticamente.

Avaliar:
- origem;
- confiança;
- licença;
- manutenção;
- compatibilidade com Antigravity;
- necessidade real.
