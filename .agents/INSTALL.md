# Instalação no Antigravity

## Por projeto

Na raiz do projeto:

```text
SEU-PROJETO/
└── .agents/
    └── skills/
```

Extraia as 11 pastas `avsm-*` para `skills/`.

## Teste

Peça:

```text
Liste as Skills AVSM disponíveis e indique quando usar AVSM LP e AVSM Web Pro.
```

Depois teste:

```text
Use AVSM Master.
Quero uma landing page simples para advocacia familiar.
```

e:

```text
Use AVSM Master.
Quero um site premium com storytelling, GSAP e Motion Level 3.
```

## Observação

Os arquivos em `_shared/` são referências internas da suíte. Não são Skills isoladas.
