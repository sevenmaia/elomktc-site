# AVSM Prompt Recipes

## 1 — LP simples

```text
Use AVSM Master.

Crie uma landing page para um advogado especialista em Direito de Família.

Modo: AVSM LP
Motion Level: 1

Objetivo:
gerar contatos pelo WhatsApp.

Prioridades:
autoridade, confiança, conversão, performance e mobile.

Não use:
Three.js, WebGL, shaders ou bibliotecas pesadas.

Não faça deploy.
```

## 2 — Site Pro editorial

```text
Use AVSM Master.

Crie um site AVSM Web Pro para um escritório de arquitetura.

Motion Level: 3.

Quero:
- direção editorial;
- tipografia forte;
- storytelling;
- GSAP/ScrollTrigger quando justificável;
- imagens grandes;
- composição premium.

Use Library Scout antes de instalar dependências.

Não adicione 3D apenas por decoração.
Não faça deploy.
```

## 3 — Site Pro 3D

```text
Use AVSM Master.

Crie um AVSM Web Pro para uma marca automotiva.

Motion Level: 5.
3D Mode: product-storytelling.

O objeto 3D deve:
- apresentar o produto;
- reagir à narrativa;
- sincronizar com scroll;
- ter fallback mobile.

Use avsm-3d e avsm-performance.
Consulte Library Scout antes de instalar bibliotecas.

Não faça deploy.
```

## 4 — Refinar um site já existente

```text
Use AVSM Design Pro.

Não redesenhe tudo.

Analise somente:
- hierarquia;
- spacing;
- typography;
- grid;
- cards;
- CTA;
- mobile.

Corrija o mínimo necessário para elevar a qualidade visual.
```
