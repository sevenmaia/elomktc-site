# AVSM Creative Suite v2

Suíte modular de Agent Skills para Google Antigravity focada em dois produtos distintos:

1. **AVSM LP** — landing pages simples, rápidas, comerciais e focadas em conversão.
2. **AVSM Web Pro** — sites premium com direção de arte, storytelling, motion, GSAP, 3D/WebGL e pesquisa de bibliotecas.

A suíte evita misturar complexidade de sites experimentais com landing pages simples.

## Regra central

**Não usar tecnologia avançada só porque ela existe.**

A stack deve seguir:
- objetivo;
- narrativa;
- UX;
- marca;
- performance;
- capacidade do dispositivo.

## Comandos rápidos

### Landing page

```text
Use AVSM Master.

Crie uma landing page para um advogado de família.

Modo: AVSM LP
Motion Level: 1

Priorize autoridade, conversão, performance e responsividade.
Não use 3D/WebGL.
Não faça deploy.
```

### Site premium

```text
Use AVSM Master.

Crie um site institucional premium para um estúdio de arquitetura.

Modo: AVSM Web Pro
Motion Level: 3

Use direção de arte, storytelling e copy avançada.
GSAP é permitido.
Consulte Library Scout antes de adicionar dependências.
Não faça deploy.
```

### Site imersivo

```text
Use AVSM Master.

Crie uma experiência web premium para uma marca automotiva.

Modo: AVSM Web Pro
Motion Level: 5
3D Mode: product-storytelling

Three.js/WebGL são permitidos.
Mantenha fallback mobile e reduced-motion.
Não faça deploy.
```
