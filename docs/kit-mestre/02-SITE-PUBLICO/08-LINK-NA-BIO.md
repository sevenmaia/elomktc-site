# Link na Bio público — `/bio`

**Referência:** `07-LINK-NA-BIO-PUBLICO.webp`.

## Layout
Página vertical mobile-first, centrada em desktop (~640px), gradiente lavanda, perfil com foto real/assinatura, título `Eloisa Cunha`, subtítulo `Marketing & Comunicação`, bio curta, redes sociais; botões prioritários e blocos abaixo.

### Ordem padrão dos links (configurável no CMS)
1. CTA principal `Fale comigo no WhatsApp` (usa número confirmado da cliente).
2. CTA secundário `Solicitar orçamento` → `/orcamento` (preferível a agenda fictícia).
3. `Conheça meus serviços` → `/` ou seção específica.
4. `Ver meu portfólio` → cases.
5. `Assistir meus vídeos` → `/videos`.
6. `Ler meus artigos` → `/artigos`.
7. `Depoimentos de clientes` **somente se existirem depoimentos aprovados**.
8. Bloco de projetos em destaque (até 3) do CMS; `Ver todos` → página de portfólio.
9. Banner CTA e rodapé de contato.

## Admin e métricas
Cada link tem título, ícone, URL, visualização, ordem, status (ligado/desligado), `open_in_new_tab`, agendamento opcional, contagem real de cliques. Prévia mobile de verdade derivada dos mesmos dados; edição de tema, fontes e cards. Link único `/bio`; QR Code gerado a partir desse URL final e só quando estiver publicado.

## Acessibilidade/segurança
Links externos validam esquemas `https` e `mailto/tel` quando pertinente. Sem URLs `javascript:` ou redirecionamentos maliciosos. Nenhuma contagem de clique falsa; tracking com privacidade e limitação de bots. Imagem otimizada.
