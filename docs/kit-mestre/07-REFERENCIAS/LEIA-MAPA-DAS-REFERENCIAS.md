# Referências visuais incluídas — mapa de uso

Estas imagens servem para **direção de design e comparação visual**, NÃO como recursos finais do site. Algumas contêm textos ou números ilustrativos; considerar decisões de brief mais importantes que elementos contraditórios nas imagens.

| `02-SOBRE-MIM-APROVADA.webp` | Sobre mim | retrato na hero sobre e trajetória; fotos originais são necessárias |
| `03-SOCIAL-MEDIA-COM-COPY.webp` | Social Media | Copywriting destacado no processo |
| `04-VIDEOS-VERTICAL-HORIZONTAL.webp` | Vídeos | formatos 9:16 e 16:9, catálogo de vídeos |
| `05-SITES-GRID-CORRIGIDO.webp` | Sites | Grid corrigido: 1 principal largo + 3 regulares |
| `06-ARTIGOS-PORTFOLIO-COPY.webp` | Artigos | copy e artigos com filtros e cards alternados |
| `07-LINK-NA-BIO-PUBLICO.webp` | Bio | mobile-first, links e CTA |
